# بطاقات سورة البقرة — رواية قالون

بطاقات لحفظ سورة البقرة برواية قالون عن نافع، مقسّمة إلى ٣٩ ثمنًا في خمسة أحزاب، مع خلاصة تفسير الشعراوي لكل آية.

- نص الآيات وخطّه وعلامات الأثمان: مصحف قالون الصادر عن مجمع الملك فهد لطباعة المصحف الشريف.
- حدود الأحزاب: التقسيم المغاربي.
- خلاصات التفسير مصوغة بتصرّف من تفسير الشعراوي في الموسوعة القرآنية: https://quranpedia.net/surah/1/2/book/18

الموقع ملف واحد: `index.html`. التقدّم في الحفظ يُحفظ على جهاز كل مستخدم.
